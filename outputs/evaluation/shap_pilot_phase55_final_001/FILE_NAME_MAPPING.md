# File Name Aliases

Two SHAP pilot output files also have shorter aliases in this public package. The aliases are provided for portability on Windows paths and are byte-identical to the original files.

| Original file | Short alias |
|---|---|
| `priority_matrix_pivot_guarded_mean_prob_non_positive.csv` | `pivot_guarded_mean_prob_non_positive.csv` |
| `priority_matrix_pivot_guarded_true_non_positive_rate.csv` | `pivot_guarded_true_non_positive_rate.csv` |
